Open Source

Most of this started as "I wish my house could do that." All of it lives on GitHub.

  • aiosecurityspy

    Async Python client for the SecuritySpy video surveillance API. Published on PyPI.

  • ha-securityspy

    Home Assistant integration for SecuritySpy cameras and motion events, built on aiosecurityspy.

  • ha-hp-printers

    Home Assistant integration for HP printers: supply levels, status, and the printer's own event log.

  • ha-xthings

    Home Assistant integration for U-tec ULTRALOQ smart locks via the Xthings OpenAPI.

  • tplink-omada-mcp

    An extended fork of an MCP server that lets AI assistants read and manage TP-Link Omada networks.
