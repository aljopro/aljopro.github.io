Clarity is a form of care

I've spent nearly 20 years building for the web, the last ten at Alkami. I spent about seven of those building the platform's frontend and the Iris Design System, then joined the architecture team, and now I lead the Admin Platform team. Most of my days are about making big systems easier to live in: moving legacy ASP.NET features to microfrontends and holding the line on accessibility and localization so the banking software we ship works for everyone who uses it.

Lately that also means bringing AI into how my team works. I use BMAD-method agent workflows for spec-driven delivery, and I build agent skills that write code documentation and encode our architecture standards.

Work

Admin Platform Modernization

Alkami Technology · Technical Lead · 2023–present

I lead the Admin Platform team through moving legacy ASP.NET features to microfrontends. Along the way we rolled out Cloudflare caching that cut static asset transfer costs about 8%, and brought AI-assisted, spec-driven agent workflows into how the team delivers. I also represent web frontend architecture on Alkami's Technical Architecture Committee.

Frontend Architecture

Book

Finding Jensen: A Path to Empathy Through Understanding

My memoir about empathy and inclusion. The idea at its center is the same one I bring to engineering: clarity is a form of care. Whether it's an API, a design system, or a hard conversation, I want the other person to be able to actually receive what's being said.

I built the pipeline that turns it into print, eBook, and web editions, and narrated and produced the audiobook myself. A sequel, Seeing Jensen, is in progress.
